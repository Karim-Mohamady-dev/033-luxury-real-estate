# ميزون أوروم — Maison Aurum

صفحة هبوط للعقارات الفاخرة بتصميم داكن وذهبي: مجموعة مساكن خاصة مع بحث وتصفية، ومعاينات خاصة، ومستشارون أولون، وآراء تجريبية، وخدمات بعناصر نائبة `{{...}}`، وأسئلة شائعة، ونموذج استفسار خاص مع تحقق وحفظ في المتصفح.

## التشغيل

```bash
npm install
npm run dev
```

## البناء

```bash
npm run build
npm run preview
```

ثنائية اللغة (العربية RTL والإنجليزية LTR) مع زر تبديل وحفظ اللغة في `localStorage`. لا توجد متغيرات بيئة.
